# 光田 PDF 工具站

合併、拆分、浮水印、頁碼 — 打開網頁就能用，檔案全程留在你的電腦。

## 功能

| 工具 | 說明 |
|---|---|
| 合併與整理 PDF | 多份檔案合成一份，拖拉調順序、刪頁、旋轉、插入空白頁。圖片也能直接加進來變成頁面 |
| 加浮水印 | 文字（可調字級、角度、透明度、顏色）或院徽 Logo 圖片，即時預覽，可指定套用頁面範圍 |
| 拆分 PDF | 點縮圖或輸入頁碼範圍，抽出需要的頁面另存新檔 |
| 加頁碼 | 五種格式、六個位置，可指定起始編號與從第幾頁開始標 |
| PDF 轉圖片 | 每頁存成 PNG 或 JPG，三種畫質可選 |
| Word 轉 PDF | Windows 與 Mac 的操作步驟說明 |

## 使用方式

打開網址就能用。不需要安裝、不需要註冊、不需要登入。建議用 Chrome 或 Edge。

Word 轉 PDF 那一步請用你電腦上的 Word 內建的「另存新檔 → PDF」，品質最好也最安全，工具裡有圖文步驟。

## 為什麼不用線上免費工具

線上 PDF 服務要把檔案**上傳到對方的伺服器**處理。醫院的公文、人事資料、病歷相關文件這樣傳出去，在資安上是有疑慮的。

這個工具所有處理都在**你自己的瀏覽器**完成，檔案不會離開你的電腦，關掉分頁就沒了。也沒有檔案大小限制、沒有每日次數上限、不會要你註冊。

## 技術說明

純靜態網頁，無框架、無建置流程、無後端。相依套件都在 `lib/`，離線也能運作。

- [pdf-lib](https://pdf-lib.js.org/) — 產生與編輯 PDF
- [pdf.js](https://mozilla.github.io/pdf.js/) — 渲染頁面縮圖與預覽

兩個實作上的注意事項，改動時請保留：

- **中文文字（浮水印、頁碼）不嵌入字型檔**，而是用 canvas 以系統中文字型畫成 4 倍超取樣的透明 PNG 再蓋上頁面。嵌入 CJK 字型會讓瀏覽器解析卡死，且 OTF 子集化有 CFF 表損毀的問題。
- **pdf.js 的 `render()` 一律帶 `intent:'print'`**。預設的 display intent 在分頁隱藏時因為 requestAnimationFrame 不觸發而永遠不會完成。

## 刻意不做的功能

PDF 轉 Word / Excel、OCR 文字辨識、PDF 壓縮——這三項純前端做不出堪用的品質（需要伺服器端的版面辨識模型），與其做出爛功能不如誠實說明，請改用其他工具。
